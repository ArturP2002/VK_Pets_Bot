Инструкция по настройке ВКонтакте для бота ExoCare+

Документ для заказчика. После выполнения шагов заполните блок «Что передать разработчику» в конце и отправьте его.


Что получится в итоге

Бот работает от имени вашего сообщества ВКонтакте:
отвечает клиентам в личных сообщениях сообщества;
создаёт заявки и пишет врачам в служебные беседы;
даёт кнопку «написать пациенту / врачу» по ссылке на профиль VK.

Для запуска разработчику нужны только данные из этого чек-листа (токен, ID сообщества, беседы, ID врачей и админов). Оплату и сервер здесь не разбираем — только ВК.


Что подготовить заранее

Сообщество (группа или паблик), куда привяжете бота — клиенты будут писать боту.
Права администратора или создателя сообщества — чтобы создать ключ и включить сообщения.
Аккаунты врачей и админов — для прав на команды и доступа к чатам.
Ориентировочно 15–30 минут на настройку интерфейса VK.


Часть 1. Сообщество

1.1. Создать или выбрать сообщество

Откройте vk.com → Сообщества → Создать сообщество
или используйте уже существующее.

Тип сообщества (бизнес, публичная страница, группа) на работу бота почти не влияет.

Запомните короткий адрес сообщества, например: vk.com/exocare.


1.2. Узнать ID сообщества (параметр VK_GROUP_ID)

Способ А (рекомендуется).

Откройте сообщество в браузере и посмотрите адрес:
если ссылка вида https://vk.com/club239246256 — ID равен 239246256;
если ссылка вида https://vk.com/public239246256 — ID равен 239246256.

Если адрес красивый (vk.com/exocare):
откройте любую запись сообщества;
в конце URL часто есть фрагмент wall-239246256_… — ID равен 239246256 (число без минуса);
либо через сервис «узнать ID ВК» по ссылке на сообщество.

Способ Б: сторонний сервис «узнать ID ВК» по ссылке на сообщество.

Важно: в настройках пишется положительное число, например 239246256, а не -239246256.


Часть 2. Сообщения сообщества (обязательно)

Откройте сообщество → Управление → Сообщения.
Включите «Сообщения сообщества».

Рекомендуемые настройки:
разрешить писать сообществу всем (или только подписчикам — по вашей политике);
приветствие можно оставить пустым: бот сам отвечает на «Начать».

Если есть раздел «Настройки для бота» — разрешите ботам отвечать от имени сообщества.

Без этого клиент не сможет писать боту, а бот — отвечать.


Часть 3. Ключ доступа сообщества (параметр VK_GROUP_TOKEN)

Это самый важный секрет. Не публикуйте его в открытых чатах, почте без защиты и на скриншотах с полным ключом. Лучше передать через защищённый канал (зашифрованный чат, менеджер паролей и т.п.).


3.1. Создать ключ

Сообщество → Управление → Настройки → Работа с API
(иногда: Управление → Дополнительно → Ключи доступа).

Нажмите «Создать ключ».

Отметьте права (нужно именно для бота ExoCare):

Сообщения сообщества — писать и читать диалоги.
Управление сообществом (если есть в списке) — управление чатами при необходимости.
Фотографии — загрузка и пересылка фото из заявок.
Документы и видео (если предлагаются) — вложения в заявках.
Остальное для MVP не обязательно.

Минимум без которого бот не заведётся: доступ к сообщениям сообщества.

Подтвердите создание (SMS или код из приложения).

Скопируйте ключ сразу — потом его часто не показывают повторно.
Вид: длинная строка, обычно начинается с vk1.a.


3.2. Long Poll API (обязательно для текущего бота)

Бот работает через Long Poll (получение событий в реальном времени), а не через Callback URL на сервере VK.

Сообщество → Управление → Настройки → Работа с API → вкладка Long Poll API
(или Bots Long Poll API).

Включите Long Poll API / Bots Long Poll API.

Версия API: 5.131 или новее (как предлагает VK; подойдёт актуальная из списка).

Типы событий — включите как минимум:
Входящее сообщение (message_new);
Действие с сообщением / событие сообщения (message_event) — обязательно для кнопок («Взять заявку», юридические галочки, тестовая оплата и т.д.).

Сохраните настройки.

Если message_event выключен: кнопки в сообщениях не будут работать, хотя текст бот может читать.


Часть 4. Беседа врачей (обязательно)

В эту беседу бот присылает новые заявки с кнопками «Взять» и «Завершить».


4.1. Создать беседу

В VK: Мессенджер → Создать беседу (или «Новый чат»).

Название — точно такое, как потом укажете в настройках, например:
Чат врачей

Регистр и пробелы важны: бот ищет чат по названию.

Добавьте участников: врачи, админы.

Обязательно добавьте само сообщество (бота) в беседу:
в участниках беседы: Добавить → найдите ваше сообщество;
выдайте сообществу право писать сообщения в беседе (если VK спрашивает права).


4.2. «Разбудить» диалог для бота

После добавления сообщества:

Напишите в беседу любое сообщение от имени сообщества
(в беседе переключите отправителя на сообщество, если VK это позволяет)
или напишите обычное сообщение и убедитесь, что сообщество видит чат.

Без этого бот часто не находит беседу среди диалогов токена сообщества.


4.3. ID беседы (параметр VK_DOCTOR_CHAT_ID) — опционально

Если название задано верно, достаточно названия (VK_DOCTOR_CHAT_TITLE). ID — запасной вариант.

Как узнать ID (если нужно):

Откройте беседу в браузере (полная версия VK).
В адресной строке будет что-то вроде:
https://vk.com/im/convo/2000000001
или sel=c1 / peer=2000000001.

Число вида 2000000001 — это peer_id беседы.
Короткий id = последняя часть: 1 (если peer = 2000000000 + 1).

Частая ошибка: подставить 2000000001 в поле VK_DOCTOR_IDS.
Это поле только для личных ID людей.

Для чата используйте только:
VK_DOCTOR_CHAT_TITLE=Чат врачей
и/или VK_DOCTOR_CHAT_ID=2000000001 (или короткий 1).


Часть 5. Чаты по срочности (рекомендуется)

Можно разделить заявки по срочности:

Срочно (красная) — пример названия: ExoCare СРОЧНО
параметр: VK_CHAT_URGENCY_RED_TITLE

Средняя (жёлтая) — пример названия: ExoCare Средняя
параметр: VK_CHAT_URGENCY_YELLOW_TITLE

Планово (зелёная) — пример названия: ExoCare Планово
параметр: VK_CHAT_URGENCY_GREEN_TITLE

Для каждой беседы:

Создайте беседу с уникальным точным названием.
Добавьте врачей и сообщество.
Напишите тестовое сообщение, чтобы диалог появился у сообщества.

Если эти чаты не нужны — оставьте названия пустыми; заявки пойдут в общий «Чат врачей».


Часть 6. ID врачей и администраторов

Нужны числовые ID пользователей, не ссылки на беседы.


6.1. Как узнать ID человека

Откройте профиль: https://vk.com/id252574410 — ID равен 252574410.

Если короткий адрес vk.com/ivanov:
откройте профиль и узнайте числовой id через сервис «узнать ID ВК»;
или попросите человека прислать ссылку с id.

Несколько людей — через запятую:
252574410,393878721


6.2. Куда что писать

VK_DOCTOR_IDS — врачи.
Могут брать и завершать заявки; опционально получают дубли заявок в личку от бота.

VK_ADMIN_IDS — админы и владельцы.
Те же права плюс админ-команды (/tickets, /payments и другие).

Один человек может быть и врачом, и админом — продублируйте ID в оба поля.


6.3. Профиль врача для кнопки клиенту

Когда врач берёт заявку, клиент получает кнопку «Написать врачу».

Заполните одно из двух:

VK_DOCTOR_PROFILE_ID — числовой id страницы врача (например 1118186286);
или VK_DOCTOR_PROFILE_URL — прямая ссылка, например https://vk.com/doctor_ivanov.

Если врачей несколько и у каждого свой профиль — профили можно позже внести в каталог врачей в боте; для старта хватит одного «главного» контакта.


Часть 7. Чаты по видам животных (опционально)

При активной подписке бот может добавлять клиента в чат вида животного.

Создайте отдельные беседы, например: «Рептилии», «Птицы», «Грызуны», «Другое».
Добавьте сообщество в каждую.
Узнайте ID чата (как в пункте 4.3) и передайте:

VK_CHAT_REPTILE — рептилии
VK_CHAT_BIRD — птицы
VK_CHAT_RODENT — грызуны
VK_CHAT_OTHER — другое

Можно передавать короткий id или число вида 2000000xxx. Если чаты пока не готовы — оставьте пустыми.

По желанию можно позже добавить ссылку-приглашение в беседу (если автодобавление через API не сработает).


Часть 8. Проверка своими руками до передачи ключа

Отметьте для себя:

Сообщения сообщества включены.
Создан ключ API с доступом к сообщениям.
Включён Bots Long Poll API.
В событиях Long Poll есть message_new и message_event.
Есть беседа врачей, сообщество в участниках, название совпадает с тем, что отправите.
Известны числовые ID врачей и админов (из ссылки вида vk.com/id…).
Ключ скопирован и нигде публично не размещён.

Минимум для запуска бота

Обязательный минимум:

VK_GROUP_TOKEN
VK_GROUP_ID
VK_DOCTOR_CHAT_TITLE (или VK_DOCTOR_CHAT_ID) и подтверждение, что сообщество в этой беседе
хотя бы один ID в VK_ADMIN_IDS или VK_DOCTOR_IDS (для управления заявками вне чата; из чата врачей кнопки тоже работают)

Без первых трёх пунктов бот не запустится или заявки не дойдут до врачей.


Частые ошибки

Бот молчит.
Причина: нет токена, Long Poll выключен или неверный VK_GROUP_ID.
Что сделать: проверить ключ, ID, Long Poll.

Кнопки не нажимаются.
Причина: нет события message_event.
Что сделать: включить в Long Poll.

Заявки не приходят в чат.
Причина: сообщество не в беседе или другое название.
Что сделать: добавить сообщество, сверить название символ в символ.

Ошибка access to chat (917).
Причина: в VK_DOCTOR_IDS указали peer_id чата.
Что сделать: указать id человека из ссылки vk.com/id…

Клиент без кнопки «врачу».
Причина: не задан профиль врача.
Что сделать: заполнить VK_DOCTOR_PROFILE_ID или URL.

Токен перестал работать.
Причина: ключ отозвали или сняли права.
Что сделать: создать новый ключ и сразу передать разработчику.


Права и безопасность

Ключ сообщества даёт полный доступ к сообщениям от имени сообщества. Храните как пароль.

При утечке: Управление → API → отозвать ключ → создать новый → сразу передать разработчику.

Не давайте ключ сторонним подрядчикам без необходимости.

Админов и врачей в VK_DOCTOR_IDS и VK_ADMIN_IDS указывайте только тех, кому доверяете команды бота.


Что делает разработчик после получения данных

Подставляет значения в конфигурацию бота.
Перезапускает сервис.
Проводит проверку: «Начать» от клиента → тестовая заявка → сообщение в чат врачей → «Взять» → уведомление клиенту.

Если на каком-то шаге интерфейс VK у вас выглядит иначе (VK часто меняет меню), пришлите скриншот экрана «Работа с API» или «Сообщения» — подскажем по актуальному виду меню.
